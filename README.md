# Приветствие по имени на Django

Учебная практика, кейс-задача № 3 - веб-приложение на Django, которое принимает имя пользователя, сохраняет его в базе данных и приветствует пользователя на главной странице.

## Возможности

- главная страница с формой ввода имени и кнопкой «Submit»;
- модель `Visitor` с одним полем `name` - таблица имён в базе данных (SQLite);
- после отправки формы имя сохраняется в базу, а на главной странице появляется приветствие «Привет, <имя>!»;
- обработка ошибок ввода: пустое поле, строка из одних пробелов, имя без букв, слишком длинное имя (больше 100 символов) - форма показывает понятное сообщение, запись в базу не создаётся;
- после успешной отправки выполняется редирект (Post/Redirect/Get), поэтому при обновлении страницы форма не отправляется повторно;
- оформление на CSS: градиентный фон, карточка по центру, стилизованные поле ввода и кнопка, подсветка ошибок.

## Безопасность

- защита от CSRF: `CsrfViewMiddleware` и тег `{% csrf_token %}` в форме, запрос без токена отклоняется с кодом 403 и понятной страницей;
- защита от XSS: имя выводится через шаблон Django с автоматическим экранированием;
- заголовки `X-Frame-Options: DENY` и `X-Content-Type-Options: nosniff`, cookie с флагами `HttpOnly` и `SameSite`;
- секретный ключ и режим отладки задаются переменными окружения `DJANGO_SECRET_KEY`, `DJANGO_DEBUG`, `DJANGO_ALLOWED_HOSTS`; при `DJANGO_DEBUG=0` cookie передаются только по HTTPS.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Приложение откроется по адресу http://127.0.0.1:8000/. Сохранённые имена можно посмотреть в админке (`/admin/`), предварительно создав пользователя командой `python manage.py createsuperuser`.

## Тесты

```
python manage.py test
```

19 тестов проверяют модель, валидацию формы, сохранение имени и приветствие, экранирование HTML, работу сессий и защиту от CSRF.

## Структура

```
    forms.py        форма NameForm и проверка имени
    views.py        представление главной страницы

    admin.py        модель в админке
    tests.py        тесты
    templates/      шаблоны страниц
    static/         стили CSS
manage.py
requirements.txt
```
